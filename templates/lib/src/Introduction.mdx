# React Lib

CSS Custom Properties 기반의 가벼운 React 컴포넌트 라이브러리입니다.

## 설치 및 사용

```ts
import { Button } from 'react-lib';
import 'react-lib/styles';
```

## 디자인 토큰

모든 토큰은 `--rl-*` 접두사를 사용합니다. 주요 그룹:

- **색상**: `--rl-color-bg`, `--rl-color-fg`, `--rl-color-primary`, `--rl-color-success`, ...
- **간격**: `--rl-space-1` ~ `--rl-space-12`
- **라운드**: `--rl-radius-sm` ~ `--rl-radius-full`
- **그림자**: `--rl-shadow-sm` ~ `--rl-shadow-xl`, `--rl-shadow-focus`
- **타이포**: `--rl-font-sans`, `--rl-font-size-xs` ~ `--rl-font-size-2xl`
- **z-index**: `--rl-z-modal`, `--rl-z-toast`, ...

토큰 정의 위치: `src/styles/tokens.css`

## 다크 모드

`document.documentElement`에 `data-theme="dark"` 속성을 부여하면 다크 토큰 세트가 적용됩니다.
훅 `useTheme()`이 localStorage와 `prefers-color-scheme`를 자동으로 처리합니다.

```tsx
import { useTheme } from 'react-lib';

function Header() {
  const { theme, toggleTheme } = useTheme();
  return <button onClick={toggleTheme}>{theme === 'dark' ? '라이트' : '다크'}</button>;
}
```

## 접근성

- 모든 인터랙티브 컴포넌트에 `:focus-visible` 링이 적용됩니다.
- 다이얼로그(Modal)는 포커스 트랩, ESC 닫기, ARIA 속성을 갖춥니다.
- 폼 컴포넌트는 label/aria-invalid/aria-describedby를 자동 연결합니다.
